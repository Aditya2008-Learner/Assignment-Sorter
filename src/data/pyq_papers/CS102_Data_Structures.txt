SECTION C: GRAPH ALGORITHMS (30 MARKS)

10. (10 Marks) Explain in detail the theory behind 'Graph Representations (Adjacency Matrix, List)' from Graph Algorithms, supporting with appropriate examples, pseudo-code, and complexity analysis.
11. (10 Marks) Explain in detail the theory behind 'BFS & DFS' from Graph Algorithms, supporting with appropriate examples, pseudo-code, and complexity analysis.
12. (10 Marks) Construct, step-by-step, a balanced binary search tree (BST) for the sequence {45, 12, 89, 34, 70, 23, 9}. Then, apply AVL rotation rules and show every single/double rotation (LL, RR, LR, RL) performed to maintain balance after inserting 55 and 61. Prove the final tree is an AVL Tree.
13. (10 Marks) State Dijkstra's shortest path algorithm and trace it on a 6-node weighted directed graph, showing all relaxations. Why does it fail with negative edge weights? Replace it with Bellman-Ford and prove its correctness using induction.
14. (10 Marks) Trace the Merge Sort and Quick Sort algorithms on the array [38, 27, 43, 3, 9, 82, 10]. Compare the best, average, and worst-case time complexity of both using the Master Theorem. Also, prove that comparison-based sorting cannot beat $\Omega(n \log n)$ in the worst case.
15. (10 Marks) Explain in detail the theory behind 'Strongly Connected Components' from Graph Algorithms, supporting with appropriate examples, pseudo-code, and complexity analysis.
